平台能力

每一项都来自内核的代码事实（接口断言），不是配置。 「引导模式」表示该平台后端尚未实现，相关功能会降级而不是假装成功。

能力可用后端说明

本机地址与 IPv6 前缀

前缀是这套系统的核心概念：ISP 重拨后变化的是整个 /64 前缀，该前缀下的所有 AAAA 记录都要重写， 而不是只改一个地址。 列表里只会出现 /64 及更粗的前缀 —— Windows 会把 IPv6 主机地址 报成 /128，而隐私扩展地址每小时轮换，把它当委派前缀会造成 每小时一次的无意义全量更新。

DNS 服务商凭据

凭据加密存储在主密钥保护的信封里。列表中只显示掩码值 —— 内核不会把明文凭据发回界面。

动态解析任务

一条任务 = 一组凭据 + 一组域名 + 一组地址来源。 地址变化会被立即触发，另有定时轮询兜底。
勾选任务的「立即执行」会清空防抖缓存，因此必定与服务商比对一次。

DNS 记录管理

仅 Tier-1 服务商可用（Cloudflare / 阿里云 / 腾讯云 / DNSPod / 华为云 / GoDaddy）。
注意各家的记录模型不同：华为云的一条记录属于一个「记录集」， GoDaddy 的记录没有独立 ID —— 它们的删除会波及同名的其它值。 详见 docs/PROVIDER-MATRIX.md。

反向代理

按域名把外部请求转发到本机的服务上。没有默认上游 —— 未配置的域名会返回 404，而不是回落到某个本地服务。
上游只允许本机与内网地址：允许公网地址会让这个功能变成一个 开放代理，任何人都能借你的机器转发流量。

转发规则

规则是整体保存的：同一个域名不能同时指向两个上游， 而增量修改会让「检查冲突」变成一件跨多次调用才能完成的事。

TLS 证书

证书由内核自动申请与续期：到期前 1/3 寿命时进入续期窗口 （对 90 天的证书即提前 30 天）。一般情况下不需要手动干预。
「需要续期」后面会给出理由 —— 一类是快过期了，另一类是 「现有证书不覆盖某个新加的域名」，而后者与剩余有效期无关。

通知通道

同一个事件在静默期内只发一条，防止地址抖动刷屏；静默期过后若期间有 被抑制的消息，会补发一条汇总。
日志通道始终可用 —— 即使没有配置任何外部通道， 通知也会出现在事件流与内核日志里。

最近的投递结果

配置通道时最常被问到的问题是「我的通知到底发出去了没有」—— 这里是答案。

系统服务

把内核注册为系统服务之后会开机自启、崩溃自动重启，不必一直开着终端。
安装与卸载需要管理员权限；在 Windows 上， 连查询服务状态也需要 —— 因此下面同时报出「内核是否可达」， 那个问题不需要任何权限就能回答。

安装服务

卸载不会删除数据目录 —— 里面有你的凭据与配置。

事件流

通过 WebSocket 实时推送。浏览器无法为 WebSocket 设置请求头， 因此令牌走 Sec-WebSocket-Protocol 子协议传递。
断线重连时会带上 lastEventId 补发漏掉的事件； 若补发链已断（环形缓冲被覆盖），会收到一条 events.gap 而不是静默丢事件。

原始接口调用

直接对内核发一次请求并看到原始响应。 验证功能的最后一道手段 —— 界面有 bug 时，这里仍然可信。
